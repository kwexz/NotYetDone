# Spec Delta

## Purpose

Даёт необязательную детерминированную проверку, которая решает, продолжать ли
цикл, не полагаясь на отчёт агента и не исполняя команды из task-файлов.

## ADDED Requirements

### Requirement: Гейт выключен по умолчанию

Гейт проверки SHALL быть выключен, пока пользователь явно не задал команду при
включении контроля.

#### Scenario: Контроль без гейта

- **WHEN** контроль включён без команды проверки
- **THEN** решение о продолжении принимается по checklist, как раньше

### Requirement: Команда только из явного ввода

Команда проверки и рабочая директория SHALL поступать только из явного ввода
пользователя через `task_continuity`. Плагин MUST NOT извлекать команды из
Markdown-файлов.

#### Scenario: Команда в task-файле

- **WHEN** в checklist встречается текст, похожий на команду
- **THEN** плагин его не исполняет и не использует как гейт

### Requirement: Код возврата решает

При настроенном гейте код 0 SHALL завершать цикл, а ненулевой код MUST
продолжать цикл с хвостом вывода, не превышая существующие лимиты.

#### Scenario: Красная проверка при закрытом checklist

- **WHEN** все пункты отмечены, но проверка вернула ненулевой код
- **THEN** продолжение ставится и содержит хвост вывода

#### Scenario: Зелёная проверка

- **WHEN** проверка вернула код 0
- **THEN** цикл завершается с состоянием пройденного гейта, а не с объявлением acceptance

### Requirement: Таймаут и лимит вывода

Запуск проверки SHALL иметь таймаут и ограничение размера вывода. Превышение
MUST считаться неуспешной проверкой с усечённым хвостом.

#### Scenario: Проверка зависла

- **WHEN** команда не завершилась за отведённый таймаут
- **THEN** проверка считается неуспешной, процесс завершается, вывод усечён

#### Scenario: Слишком много вывода

- **WHEN** команда вывела больше установленного лимита
- **THEN** в продолжение попадает только хвост в пределах лимита

### Requirement: Результат виден в status

`status` SHALL показывать последний результат проверки: код возврата, время
запуска и усечённый вывод.

#### Scenario: Пользователь проверяет гейт

- **WHEN** пользователь запрашивает `action=status` после запуска гейта
- **THEN** ответ содержит код, время и хвост вывода последней проверки

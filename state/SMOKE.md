# Smoke: автопродолжение и остановка

Отдельная диагностика плагина. Не разрешение на продуктовые задачи и не
повод менять код.

**Как проводить:** включить `task_continuity` для этого файла и в каждом ходе
выполнять **ровно один** пункт, затем завершать ход. Ничего кроме записи в
`state/SMOKE_LOG.md` не делать.

- [ ] 1. Дописать строку `smoke-1` в `state/SMOKE_LOG.md`.
- [ ] 2. Дописать строку `smoke-2` в `state/SMOKE_LOG.md`.
- [ ] 3. Дописать строку `smoke-3` в `state/SMOKE_LOG.md`.

## Что должно произойти

1. После пункта 1 приходит автоматический prompt → пункт 2.
2. После пункта 2 приходит автоматический prompt → пункт 3.
3. После пункта 3 продолжения **нет**: checklist закрыт, состояние
   `Checklist complete`.
4. Всего автоматических prompt: ровно 2. Третий — дефект.

## Evidence

Заполнить после прогона:

- Автоматических продолжений: _не заполнено_
- Финальный статус (`task_continuity action=status`): _не заполнено_
- Лишние prompt после закрытия checklist: _не заполнено_
- Дата и версия OpenCode: _не заполнено_

## Что должно произойти

1. После пункта 1 приходит автоматический prompt → пункт 2.
2. После пункта 2 приходит автоматический prompt → пункт 3.
3. После пункта 3 продолжения **нет**: checklist закрыт, состояние
   `Checklist complete`.
4. Всего автоматических prompt: ровно 2. Третий — дефект.

доставляет их по одному после завершения очередного хода. Живой smoke
считается **непройденным**.

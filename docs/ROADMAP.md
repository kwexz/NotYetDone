# Дорожная карта

Фазы идут по порядку. Каждая заканчивается проверяемым результатом, а не
«сделано». Не начинать следующую, пока текущая не прошла acceptance.

## Фаза 0 — доказать, что текущее работает

- [ ] Живой smoke по `state/SMOKE.md`: два пункта, автопродолжение, затем
      остановка на закрытом checklist.
- [ ] Убедиться, что после исправления нет второго prompt.
- [ ] Записать evidence в `state/STATUS.md`.

**Acceptance:** два автоматических продолжения, ноль лишних, состояние
`Checklist complete` в конце.

## Фаза 1 — стагнация по tool-событиям

- [ ] Считать tool-события между двумя успешными исполнениями.
- [ ] Ноль инструментов + неизменный digest = стагнация, отдельный счётчик.
- [ ] `status` показывает оба счётчика.

**Acceptance:** тест, где агент «работает» без инструментов, останавливается
раньше, чем по лимиту 12.

## Фаза 2 — детерминированный гейт

- [ ] Необязательный `check` в состоянии (команда + рабочая директория).
- [ ] Запуск только по явному согласию пользователя.
- [ ] Код 0 — продолжение разрешено; иначе продолжение с хвостом вывода.
- [ ] Таймаут и ограничение размера вывода.

**Acceptance:** тест, где checklist закрыт, но тест падает — продолжение
происходит; и наоборот, тест зелёный — цикл завершается.

## Фаза 3 — resume и blocked_external

- [ ] `action=resume` без сброса счётчиков.
- [ ] `blocked_external` как отдельное состояние с причиной и списком
      сделанного.
- [ ] `status` различает paused / blocked / complete / limit.

**Acceptance:** после перезапуска OpenCode состояние читается и resume
продолжает с теми же счётчиками.

## Фаза 4 — восстановление после compaction

- [ ] Проверить, какие события компакции есть в V2.
- [ ] При включённом контроле возвращать состояние задачи после сжатия.

**Acceptance:** тест на событие компакции; при отсутствии события — честный
`not-run` с описанием.

## Фаза 5 — решение о публикации

- [ ] Сравнить с `untildone` на Linux/macOS (сейчас `blocked_external`).
- [ ] Проверить, остался ли сценарий, который не закрывают аналоги.
- [ ] Если да — публичный README с честным сравнением, npm, тег.
- [ ] Если нет — оставить личным инструментом и не публиковать.

**Acceptance:** явное решение, записанное в `DECISIONS.md`.

## Фаза 6 — другие рантаймы (только после 0–5)

затем остальные. Ядро политики отдельно от адаптера. Не начинать, пока
OpenCode-адаптер не доказан живыми прогонами.
